# 💎 Devi Jewels

A modern and elegant jewellery e-commerce website designed to showcase beautiful jewellery collections with a premium shopping experience.

## 🌐 Live Website

🔗 https://dodlayeshwanth-max.github.io/devi-jewels/

## ✨ Features

- 🏠 Elegant Home Page
- 💍 Jewellery Collections
- 🛒 Shopping Cart
- ❤️ Wishlist
- 👤 User Account
- 🔐 Admin Panel
- 📱 Responsive Design
- 🎨 Premium Jewellery UI
- 💾 Local Storage for Cart and Account Data

## 🛍️ Website Pages

- **Home** – `index.html`
- **Collections** – `collections.html`
- **Cart** – `CART.HTML`
- **My Account** – `account.html`
- **Admin** – `admin.html`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- SQLite
- Git & GitHub
- GitHub Pages
